# Obsidian

- 项目是什么：面向 TikTok 英国跨境电商选品的网页工作台。
- 解决的需求：导入 Echotik 导出的商品列表 Excel，在网页中查看商品图片和关键数据，通过筛选找到值得进一步采集和跟卖的商品。
- 第一阶段：支持 Echotik 近7天 / 近30天商品列表和小店列表 Excel；商品模块会按表头自动识别周期，并分别保存每个周期的数据、筛选与排序状态。
- 筛选与排序：总销量、当前周期销量支持最小值/最大值区间筛选；达人数和视频数支持预设百分位档位筛选；支持组合筛选、清除筛选、结果数量显示和关键数字字段排序。
- 交互与界面：商品图片、名称或操作入口可打开原商品页；采用成熟数据 SaaS / Echotik 风格，优先桌面端效率。
- 数据口径：第一版忽略“主要带货方式”；达人和视频指标仅作商品卡潜力的辅助判断，不定义为真实商品卡销售占比。
- 店铺榜单：提供小店列表、跨境卖家榜和本土卖家榜三种独立视图；卖家榜共用同一 Excel 结构，由用户选择对应榜单后导入，保留 Excel 超链接并支持筛选和排序。
- 数据保存：Excel 仅在浏览器本地解析；解析后的工作台数据会保存在当前浏览器/设备的 IndexedDB 中，可随时通过顶部入口清除。
- 在线访问：https://czh2403643561-lab.github.io/Obsidian/
- 本地运行：执行 `npm install` 安装依赖，再执行 `npm run dev` 启动本地开发页面；执行 `npm run build` 验证生产构建。
